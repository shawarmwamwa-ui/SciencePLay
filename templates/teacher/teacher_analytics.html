              Participation Rate Calculation
              Definition

              Measures classroom adoption and engagement across the SciencePlay platform. It represents the proportion of enrolled students who have actively interacted with at least one lesson or game activity.

              Mathematical Formula
              Participation Rate = ( Active Students / Total Enrolled Students ) × 100%
              Current Class Breakdown
              • Active Students (with ≥ 1 attempt): {{ analytics_stats.active_students_count }} students
              • Total Enrolled Students: {{ analytics_stats.total_students }} students
              • Calculated Rate: ({{ analytics_stats.active_students_count }} / {{ analytics_stats.total_students }}) × 100 = {{ analytics_stats.participation_rate }}%
              • Overall Assignment Completion: {{ analytics_stats.completed_count }} of {{ analytics_stats.total_assignments }} tasks ({{ analytics_stats.overall_completion_rate }}%)
              Activity Completion Calculation
              Definition

              Evaluates student follow-through on assigned interactive tasks. It calculates the percentage of teacher-assigned mini-games that students completed through to the end.

              Mathematical Formula
              Activity Completion Rate = ( Completed Activities / Total Assigned Activities ) × 100%
              Current Class Breakdown
              • Completed Activity Assignments: {{ analytics_stats.activity_comp_count }} tasks
              • Total Activity Assignments: {{ analytics_stats.total_activity_assignments }} tasks
              • Calculated Rate: ({{ analytics_stats.activity_comp_count }} / {{ analytics_stats.total_activity_assignments }}) × 100 = {{ analytics_stats.activity_completion_rate }}%
              • Class Average Game Score: {{ analytics_stats.avg_score }} pts across {{ analytics_stats.total_attempts }} attempts
              Time on Task Calculation
              Definition

              Measures cumulative instructional engagement duration. Tracks the exact time (in seconds and minutes) students spent actively viewing slides and answering embedded checkpoint questions.

              Mathematical Formula
              Total Time = ∑ Duration(Attempt_i)
              Average Visit = ∑ Duration / Total Visits
              Current Class Breakdown
              • Total Cumulative Time on Task: {{ analytics_stats.total_time_formatted }} ({{ analytics_stats.total_time_seconds }}s)
              • Average 1st Visit (Baseline): {{ analytics_stats.avg_first_time }} ({{ analytics_stats.first_attempts_count }} visits)
              • Average Revisit / Review Time: {{ analytics_stats.avg_revisit_time }} ({{ analytics_stats.revisit_attempts_count }} reviews)
              • Interpretation: First visits are exploratory; revisits show review efficiency.
              Game Replay Rate Calculation
              Definition (Thesis §2.d)

              Evaluates gamification replayability and self-directed mastery. It represents the percentage of active game players who voluntarily replayed an educational game multiple times (≥ 2 attempts) to improve their score.

              Mathematical Formula
              Replay Rate = ( Players with ≥ 2 attempts on same game / Total Active Players ) × 100%
              Current Class Breakdown
              • Replaying Players (≥ 2 attempts): {{ analytics_stats.replay_active_players }} students
              • Total Distinct Game Players: {{ analytics_stats.replay_distinct_players }} students
              • Player Replay Rate: ({{ analytics_stats.replay_active_players }} / {{ analytics_stats.replay_distinct_players }}) × 100 = {{ analytics_stats.replay_rate }}%
              • Whole Class Proportion: {{ analytics_stats.class_replay_rate }}% of all {{ analytics_stats.total_students }} enrolled students
